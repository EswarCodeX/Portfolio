## 🚀 Getting Started

> **Prerequisites:** [Bun](https://bun.sh/) runtime installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/EswarCodeX/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
bun install
```

### 3. Run the development server
```bash
bun dev
```

### 4. Build for production
```bash
bun run build
bun start
```
